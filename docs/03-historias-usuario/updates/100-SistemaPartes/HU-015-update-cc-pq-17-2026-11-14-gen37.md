## Narrativa

Como usuario con asistencia IA en el diseñador de Consulta detallada, quiero que el sistema resuelva frases como «sumá las horas» al campo técnico `duracionMinutos` mediante `label`/`description`/`synonyms` del **mismo** schema JSON, sin un diccionario inventado en el planner.

## Criterios de aceptación

1. Todos los fields de `partes.informes.consultaDetallada.json` tienen `description` y al menos un `synonym` útil donde aplique (códigos cortos pueden tener synonyms vacíos o mínimos).
2. Ningún sinónimo ambiguo apunta a dos `name` del mismo proceso.
3. El turno SC / planner incluye el vocabulario del JSON en el prompt (no lista hardcode distinta del schema).
4. Smoke: pedido con sinónimo de duración → acción sobre `duracionMinutos`.
